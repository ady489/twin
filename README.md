# AI Digital Twin

An AI-powered Digital Twin web application that represents me through an interactive AI assistant. The project allows visitors to communicate with the Digital Twin using natural language and get information about me, my background, skills, projects, and interests.

## 📌 About the Project

The goal of this project was to explore how AI can be used to create a more interactive and personalized way of presenting information about a person.

Instead of using a traditional portfolio website, I wanted to create an AI-powered assistant that visitors can interact with through natural conversations.

The Digital Twin can answer questions and provide information based on the data and instructions provided to it.

## ✨ Features

- 🤖 AI-powered conversational assistant
- 💬 Natural language interaction
- 👤 Personalized responses about me
- 📚 Information about my education and background
- 💻 Information about my technical skills and projects
- 🌐 Web-based user interface
- 📱 Contact system for visitors
- 🔔 Push notifications when someone leaves their email
- 🚀 Deployed and accessible online

## 🧠 How It Works

The application works as an AI-powered conversational interface.

A simplified flow of the system is:

User
↓
Web Interface
↓
AI Assistant
↓
Personal Information / Project Data
↓
Generated Response
↓
User

The AI receives the user's question, processes it using the configured AI model and available information, and generates a response.

## 📩 Contact Feature

One of the features I implemented is an AI-powered contact system.

If a visitor wants to get in touch with me, they can leave their email through the Digital Twin.

After the visitor submits their email:

1. The email is received by the backend.
2. A notification is triggered.
3. I receive a push notification on my phone.
4. I can then follow up with the person.

This was implemented to make the Digital Twin more than just a chatbot and give it a practical communication feature.
